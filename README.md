# MiTaller
Sistema web para gestionar el historial de mantenimiento, reparaciones, gastos y cambios de repuestos de cualquier vehículo.

## Características

- Gestión de vehículos
- Historial de mantenimientos
- Gestión de repuestos
- Registro de gastos
- Recordatorios

## Tecnologías

- Laravel 12
- Filament 4
- MySQL
- Docker
- GitHub Actions
