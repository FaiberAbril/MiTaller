# MiTaller

Sistema de gestión de historial vehicular desarrollado con Laravel y Filament.

## Objetivo

Permitir a los usuarios registrar y consultar toda la información relacionada con el mantenimiento de sus vehículos.

## Funcionalidades

- Gestión de vehículos
- Historial de mantenimientos
- Gestión de repuestos
- Registro de gastos
- Recordatorios
- Dashboard de estadísticas

## Tecnologías

- Laravel
- Filament
- MySQL
- PHP
- GitHub Actions
